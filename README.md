# BlockFire — موقع تسويقي ومُجمِّع طلبات واتساب

موقع احترافي لتسويق جهاز إطفاء تلقائي بالأيروسول الحراري. الموقع لا يحتوي على
دفع إلكتروني: يتيح للزائر اكتشاف المنتج، اختيار الكمية، ثم إرسال طلبه مباشرة عبر
واتساب.

Stack : **React + Vite + TypeScript + Tailwind CSS + lucide-react**.
اللغة الرئيسية للموقع: **العربية** (RTL) — مع الاحتفاظ بالمصطلحات التقنية
بالفرنسية/الإنجليزية عند الحاجة (مثل أسماء المعايير أو الوحدات).

---

## 1. تثبيت Node.js (إذا لم يكن مثبتاً بعد)

1. اذهبوا إلى https://nodejs.org
2. حمّلوا نسخة **LTS** وثبّتوها (التالي ← التالي ← إنهاء).
3. تحققوا من التثبيت. افتحوا الطرفية (Terminal) واكتبوا:

   ```
   node -v
   npm -v
   ```

   يجب أن يظهر رقم إصدار لكل أمر. إذا ظهر خطأ "الأمر غير موجود"، أعيدوا تشغيل
   الحاسوب وحاولوا مجدداً.

## 2. فتح المشروع في VS Code

1. حمّلوا وثبّتوا VS Code: https://code.visualstudio.com
2. **File → Open Folder...** ثم اختاروا مجلد `fireguard-site`.
3. افتحوا الطرفية المدمجة: **Terminal → New Terminal**.

## 3. تثبيت الحزم

في طرفية VS Code:

```
npm install
```

يجب أن يظهر في النهاية: `added XXX packages`. قد يستغرق دقيقة أو دقيقتين.

**في حال ظهور خطأ**: تحققوا من اتصال الإنترنت وأعيدوا المحاولة. إذا استمر
الخطأ، احذفوا مجلد `node_modules` إن وُجد وكرروا `npm install`.

## 4. تشغيل الموقع محلياً (وضع التطوير)

```
npm run dev
```

سيظهر رابط مثل:

```
VITE ready
➜  Local:   http://localhost:5173/
```

افتحوا هذا الرابط في المتصفح. أي تعديل تقومون به في الكود ينعكس فوراً.

للإيقاف: `Ctrl + C` داخل الطرفية.

## 5. تعديل المعلومات الأساسية

### 5.1 رقم واتساب

الملف: `src/config/contact.ts`

```ts
export const WHATSAPP_NUMBER = "212661977623"; // ⬅️ بدون "+" وبدون مسافات
```

### 5.2 اسم الشركة / الشعار

الملف: `src/config/company.ts` — الحقل `logoText` هو الاسم الظاهر في الهيدر
والفوتر.

### 5.3 صور المنتج والفيديو التوضيحي

- صور المنتج موجودة في `public/products/` وتُستخدم في `src/data/products.ts`
  (الحقل `images`).
- الفيديو التوضيحي موجود في `public/videos/blockfire-how-it-works.mp4` ويظهر
  في قسم "طريقة العمل" (`src/components/HowItWorks.tsx`).
- لإضافة صور أو فيديو جديد، ضعوا الملف داخل `public/products/` أو
  `public/videos/` وحدّثوا المسار في الملف المعني.

### 5.4 السعر ونظام الخصم

الملف: `src/config/pricing.ts`

```ts
export const BASE_UNIT_PRICE = 160; // سعر القطعة الأولى، شامل التوصيل
export const EXTRA_UNIT_DISCOUNT = 10; // الخصم عن كل قطعة إضافية
```

مثال: طلب 3 قطع = 160 + 150 + 150 = 460 درهم.

### 5.5 المواصفات التقنية

الملف: `src/data/products.ts` — كل حقل مأخوذ حرفياً من ملصق المنتج. إذا رغبتم
بتحديث أي معلومة، عدّلوها مباشرة هناك. أي حقل غير متوفر يُترك `null` ولا يظهر
في الموقع تلقائياً.

### 5.6 الأسئلة الشائعة، مجالات الاستخدام، آراء العملاء

- `src/data/faq.ts`
- `src/data/applications.ts`
- `src/data/testimonials.ts` (يبقى القسم مخفياً ما دام الجدول فارغاً — أضيفوا
  فقط آراء حقيقية)

### 5.7 الوثائق التقنية (الورقة التقنية، دليل الاستخدام، الشهادات)

1. ضعوا ملفات PDF داخل `public/documents/`.
2. في `src/data/documents.ts`، فعّلوا `available: true` مع المسار الصحيح لكل
   وثيقة متوفرة. الأزرار تظهر تلقائياً فقط للوثائق المفعّلة.

## 6. اختبار طلب عبر واتساب

1. شغّلوا الموقع (`npm run dev`).
2. في قسم "جهّز طلبك"، اختاروا الكمية.
3. أدخلوا الاسم ورقم الهاتف على الأقل، ثم اضغطوا **"إتمام الطلب عبر واتساب"**.
4. سيُفتح واتساب (تطبيق أو واتساب ويب) برسالة جاهزة تحتوي على الكمية والسعر
   الإجمالي.

## 7. بناء نسخة الإنتاج

```
npm run build
```

الملفات النهائية تُنشأ في مجلد `dist/`. لمعاينتها محلياً قبل النشر:

```
npm run preview
```

---

## 8. نشر الموقع أونلاين

مجلد `dist/` هو موقع ثابت (static) يمكن نشره على أي مستضيف. الأسهل للمبتدئين:

**Vercel:**
1. أنشئوا حساباً على https://vercel.com
2. `npm install -g vercel`
3. داخل مجلد المشروع، اكتبوا `vercel` واتبعوا التعليمات.

**Netlify:**
1. أنشئوا حساباً على https://netlify.com
2. اسحبوا مجلد `dist/` إلى صفحة "Deploy manually"، أو اربطوا مستودع Git
   (Build command: `npm run build`, Publish directory: `dist`).

## 9. هيكلة المشروع

```
src/
  components/     → جميع أقسام الموقع (Header, Hero, Product, FAQ...)
  data/           → محتوى قابل للتعديل (منتج، أسئلة شائعة، مجالات استخدام...)
  config/         → إعدادات مركزية (الشركة، التواصل/واتساب، التسعير)
  context/        → حالة الطلب العامة (الكمية المختارة)
  utils/          → توليد روابط واتساب، حساب الأسعار، التتبع
  pages/
    Home.tsx      → يجمّع كل الأقسام بالترتيب
public/
  products/       → صور المنتج
  videos/         → الفيديو التوضيحي
  documents/      → الوثائق التقنية (PDF)
```

---

## 10. حول دقة المعلومات

جميع الخصائص التقنية (وزن المادة، المساحة المحمية، نطاق درجة الحرارة، العمر
الافتراضي، كثافة الإطفاء، المعيار...) منقولة حرفياً من ملصق المنتج الحقيقي.
أي معلومة غير واردة على الملصق (مثل الأبعاد أو درجة حرارة التفعيل الدقيقة) لم
تُذكر ولم تُخترع — عدّلوها في `src/data/products.ts` فور توفر المعلومة الرسمية
من الشركة الصانعة.

## 11. Analytics (اختياري)

الملف `src/utils/analytics.ts` يتتبع الأحداث التالية:
`click_whatsapp`, `add_product`, `request_quote`, `view_product`,
`complete_whatsapp_order`. أضيفوا سكريبتات Google Analytics / Meta Pixel في
`index.html` عند توفر المعرّفات الخاصة بكم.
